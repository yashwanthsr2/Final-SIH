🤖 Model Center
ℹ Model Architecture

All CyberSentinel ML models use HistGradientBoostingClassifier (sklearn) with the following design rationale:

  • Handles missing/NaN values natively — critical for network telemetry
  • Efficient on small-medium datasets (thousands to hundreds of thousands of samples)
  • Provides feature_importances_ for explainability without SHAP overhead
  • Fast inference (<5ms per sample) — suitable for real-time detection
  • Temporal features (lag, rolling) capture behavioural patterns over time

Recon and Exfiltration detectors use statistical/rule-based methods due to limited labeled data in those categories — a deliberate, honest design decision.
