# Modern dataset sources

1. University of West Florida UWF Network Traffic Flow Datasets
   https://datasets.uwf.edu/data/

2. UWF-ZeekDataSum25-1 CSV root
   https://datasets.uwf.edu/data/UWF-ZeekDataSum25-1/csv/

3. UWF-ZeekDataSum25-2 CSV root
   https://datasets.uwf.edu/data/UWF-ZeekDataSum25-2/csv/

4. 2025 research paper using UWF-ZeekDataSum2025-1 and UWF-ZeekDataSum2025-2
   Feature Selection for Improving ANN and CNN Models for Attack Detection in Zeek Network Data.

Important: the published research metrics are literature results, not CODEZILLA results. CODEZILLA metrics must be generated by running scripts/validate_2025_uwf.py on the downloaded data.
